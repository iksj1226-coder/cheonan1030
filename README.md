# 천안 웰니스 2026 — 인터랙티브 웹 프레젠테이션

첨부된 `천안시_웰니스_전략발표_10장.pptx`를 기반으로 제작한 정적 웹 프레젠테이션입니다.
별도 서버, 데이터베이스, 빌드 과정, 외부 CDN 또는 웹 폰트 없이 동작합니다.

## 시작하기

`index.html`을 브라우저에서 열면 됩니다. 인터넷 연결 없이도 로컬에서 사용할 수 있습니다.

## GitHub Pages 게시

1. 새 GitHub 저장소를 만들고 `index.html`, `styles.css`, `script.js`, `favicon.svg`, `assets/` 폴더를 저장소 루트에 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
3. **Branch: main / (root)**를 선택하고 저장합니다.
4. 생성된 GitHub Pages 주소에서 웹 프레젠테이션을 확인합니다.

> 저장소를 하위 경로(예: `username.github.io/repository/`)로 게시해도 리소스 경로가 상대 경로이므로 작동합니다.

## 조작

- 상단 목차를 클릭하거나 우측 상하 이동 버튼을 눌러 슬라이드를 전환합니다.
- 마우스 휠, 터치 스크롤, `↑` / `↓` / `PageUp` / `PageDown` / `Home` / `End` / `Space` 키를 사용할 수 있습니다.
- 일부 카드(웰니스 프레임, 주요 공간, 문화행사)를 누르면 원본에 있는 상세 설명을 볼 수 있습니다.
- 상단 **원본** 버튼은 원본 PPTX를 렌더링한 슬라이드 이미지와 재구성된 웹 화면을 전환합니다.
- 상단 전체화면 버튼은 프레젠테이션 전체 화면을 전환합니다(브라우저 권한에 따라 제한될 수 있음).
- `#slide-1`부터 `#slide-10`까지 해시 링크로 특정 슬라이드를 바로 열 수 있습니다.

## 내용 및 출처

- PPTX의 기존 10장에 있는 제목, 수치, 도표, 본문, 일정, 제안과 확정사업 구분을 근거로 재현했습니다.
- 행사 일정, 수치, 정책 상태는 **원본 PPTX에 기재된 2026-10-30 기준**을 유지하며 새롭게 검증하지 않았습니다.
- `assets/image-*.png`는 원본 PPTX에 포함된 삽화/아이콘을 추출한 파일입니다.
- `assets/original/slide-*.png`는 원본 레이아웃과 내용이 완전히 보존되도록 PPTX를 렌더링한 이미지입니다.
- 모든 리소스는 상대 경로로 로드되며 개인정보 수집, 서버 통신, 추적 분석 기능이 없습니다.

## 파일 구성

```
index.html             10장 HTML 콘텐츠
styles.css             레이아웃, 반응형 디자인, 전환 애니메이션
script.js              내비게이션, 카드 팝업, 전체화면, 수치 애니메이션
favicon.svg            파비콘
assets/image-*.png     원본 이미지/아이콘
assets/original/       10장 원본 슬라이드 이미지
```
